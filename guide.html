📱 당첨내역 캡쳐 방법 안내

1. 하단 '청약' 메뉴 클릭
LH 청약플러스 앱(또는 모바일웹) 메인 화면 하단에 있는 '청약' 버튼을 눌러주세요.
2. 우측 상단 '전체 메뉴' 클릭
청약 화면으로 이동한 후, 우측 상단의 전체 메뉴(가로줄 3개 아이콘)를 선택합니다.
3. '청약결과 확인' 메뉴 선택
왼쪽 탭 메뉴를 아래로 내려 '청약결과 확인'을 눌러주세요.
4. '당첨/낙찰 결과조회' 선택
오른쪽에 나타나는 세부 메뉴 중 '당첨/낙찰 결과조회'를 선택합니다.
5. 최종 당첨내역 캡쳐
조회화면의 신청자명, 단지명(부천역곡[A2]), 동호수가 명확히 보이도록 화면을 캡쳐해 주세요.
