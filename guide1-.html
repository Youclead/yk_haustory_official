💬 단체방 입장 코드 요청 방법

1. 오픈채팅 검색 열기
카카오톡 하단 오픈채팅 탭을 누른 후, 우측 상단의 검색(돋보기) 버튼을 선택해 주세요.
2. 공식 오픈채팅방 검색
검색창에 '역곡지구 하우스토리'를 검색하여 목록에서 [공식]역곡지구 하우스토리 방을 선택해 주세요.
3. 방장 프로필 선택
방 정보 화면 하단에 있는 방장 프로필 '언제나가자/209동'을 눌러주세요.
4. 1:1 오픈채팅으로 입장 요청
1:1 오픈채팅 버튼을 눌러 당첨자 인증 화면을 보내주시면, 확인 후 단체방 입장 코드를 안내해 드립니다.
